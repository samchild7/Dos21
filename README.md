# dos21.org

The DOS21 site: a practice of The Jefferson Way.

- `index.html` is the DOS21 page at https://dos21.org/
- `jefferson-way.html` is The Jefferson Way page at https://dos21.org/jefferson-way.html

Both pages are self-contained HTML with no build step. Edit a page and commit; GitHub Pages republishes in about a minute.

Links that appear only once set live in the `CONFIG` block near the end of each page (for example `ASSESSMENT_URL`).
